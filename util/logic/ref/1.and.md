# Logic matrix
The logic matrix identifies the possible operands and their corresponding outcomes.

For more details relating to the behavior results based on the operand results, see the [logic behavior matrix](x_logic.md).

| OperandA | OperandB | Operand result |
|---------|---------|--------|
| `true` | `true` | `true` |
| `true` | `false` | `false` |
| `true` | `boolean` | `boolean` |
| `false` | `true` | `false` |
| `false` | `false` | `false` |
| `false` | `boolean` | `false` |
| `boolean` | `true` | `boolean` |
| `boolean` | `false` | `false` |
| `boolean` | `boolean` | `boolean` |

> [!NOTE]
> The `boolean` result is dependent on the setting of the `UseUnsafe` capability.
